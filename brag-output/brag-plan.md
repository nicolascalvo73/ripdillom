# Brag Plan: rip.dillom — La nueva violencia

## What is this app?
Sitio interactivo (Mondilab de Mondi Studio): un comuñe 3D de Dillom para girar, tocar y tatuar; cada parte del cuerpo abre una sección.

## The angle
El menú es el cuerpo. El video recorre TODAS las pantallas reales del sitio (no solo la principal): cabeza → Música, pecho → Videos, brazos → Redes / Shows, espalda → Tienda, billete → Tomá $100, y el modo Tatuador. Estética fotocopia/sticker del propio sitio.

## Hook (0–3.3s)
Pantalla principal (comuñe + "LA NUEVA VIOLENCIA") y el sticker: "UN COMUÑE 3D" / "PARA GIRAR, TATUAR Y TOCAR." (copy de og:description).

## Key moments
- Tour de 6 pantallas, un corte por cada 3 beats, con etiqueta "PARTE DEL CUERPO ▸ SECCIÓN" y barra de navegación inferior que marca dónde estamos.
- Modo Tatuador con la paleta: cursor simulado elige un tatuaje (3.3s).

## Outro / punchline
"rip.dillom" · "Un Mondilab de Mondi Studio" · labs.mondistudio.com.ar/dillom

## User flow worth showing
Entrar → tocar una parte del cuerpo → se abre su panel → volver / probar el tatuador.
